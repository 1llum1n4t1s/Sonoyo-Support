# Sonoyo Support

ここは、Google 検索の追加調査を表示する Chrome / Firefox 拡張 **其宵（Sonoyo）** の公開サポート窓口です。

- [不具合を報告する](https://github.com/1llum1n4t1s/Sonoyo-Support/issues/new?template=bug_report.yml)
- [機能を提案する](https://github.com/1llum1n4t1s/Sonoyo-Support/issues/new?template=feature_request.yml)
- [使い方について質問する](https://github.com/1llum1n4t1s/Sonoyo-Support/issues/new?template=question.yml)
- [既存の Issue を確認する](https://github.com/1llum1n4t1s/Sonoyo-Support/issues)
- [Sonoyo 公式サイト](https://sonoyo.kagayoi.com/)

Sonoyo のソースコードは非公開です。このリポジトリでは、不具合報告、機能要望、使い方に関する質問を受け付けています。コード変更の Pull Request は受け付けていません。

## 投稿前の確認

1. [既存の Issue](https://github.com/1llum1n4t1s/Sonoyo-Support/issues) に同じ内容がないか確認してください。
2. Chrome または Firefox の拡張機能管理画面で、使用中の Sonoyo のバージョンを確認してください。
3. 不具合の場合は、可能であれば再現手順、期待していた動作、使用ブラウザを記載してください。
4. 画像やログを添付する場合は、検索語や個人情報、認証情報が含まれていないことを確認してください。

## 公開しない情報

Issue はインターネット上で誰でも閲覧できます。次の情報は投稿しないでください。

- OpenAI API キー、アクセストークン、Cookie、署名済み credential
- 月額プランの購入時メールアドレスや6桁の確認コード
- 公開したくない検索語、検索結果、閲覧履歴
- 個人名、住所、ユーザー名などの個人情報
- 個人情報や認証情報が映り込んだスクリーンショット

投稿後に機密情報へ気づいた場合は、Issue の本文を編集して取り除いてください。脆弱性やセキュリティ上の問題は、公開 Issue ではなく[セキュリティ報告](https://github.com/1llum1n4t1s/Sonoyo-Support/security/advisories/new)を利用してください。

## 対応環境

Sonoyo は Chrome 116 以降、Firefox 142 以降に対応しています。最新版とプライバシーポリシーは [Sonoyo 公式サイト](https://sonoyo.kagayoi.com/)から確認できます。

## 返信について

内容を確認したうえで、必要に応じて追加情報をお願いします。報告されたすべての要望の実装や、個別の対応期限を約束するものではありません。
